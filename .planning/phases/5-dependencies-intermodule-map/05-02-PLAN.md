<objective>
Propósito: Producir el mapa completo de dependencias entre módulos — referencias de clases entre módulos, tablas DB compartidas de alto acoplamiento, y hotspots de mayor riesgo para la reescritura con notas de complejidad de migración.

**Hallazgo arquitectónico crítico a incorporar**: `departure_control_controller.class.php` es el núcleo del sistema (24 dependencias directas confirmadas via P2C). El mapa debe construirse desde afuera hacia adentro — `departure_control` en el centro. El output principal de este plan es el **orden de reescritura** clasificado por profundidad de acoplamiento con departure_control:
- Nivel 0 (cero dependencia departure_control) → extraíbles inmediatamente
- Nivel 1 (dependencia indirecta) → segunda ola de extracción
- Nivel 2 (dependencia directa) → tercera ola — requieren API de orquestación
- `departure_control` mismo → último en migrarse

Salida: `.planning/phases/5-dependencies-intermodule-map/MAPA-DEPENDENCIAS-INTERMODULO.md`
</objective>

<task type="auto">
  <name>Tarea 3: Identificar y clasificar hotspots de mayor riesgo</name>
  <files>.planning/phases/5-dependencies-intermodule-map/MAPA-DEPENDENCIAS-INTERMODULO.md</files>
  <action>
    Un hotspot es cualquier elemento que cumpla uno o más de:
    - Clase referenciada por 3+ módulos distintos
    - Tabla DB con múltiples escritores de módulos distintos
    - Servicio con lógica de múltiples dominios mezclados
    - Dependencia bidireccional entre dos módulos

    Basándote en las tareas 1-2, identifica los hotspots.
    Para cada hotspot, usa `mcp__project2context__get_function_details` para evaluar la complejidad real.

    Documenta en MAPA-DEPENDENCIAS-INTERMODULO.md bajo "## Hotspots de Mayor Riesgo para la Reescritura":
    Para cada hotspot:

    ### [Nombre del elemento]
    - **Tipo**: Clase / Tabla / Servicio
    - **Ruta real**: [ruta del archivo o nombre de tabla]
    - **Módulos afectados**: [lista]
    - **Complejidad de migración**: Alta / Media
    - **Nota de migración**: [estrategia concreta: "extraer como API interna", "duplicar por módulo", "servicio compartido", "reescribir desde cero"]
    - **Evidencia**: [qué encontró P2C que lo clasifica como hotspot]
  </action>
