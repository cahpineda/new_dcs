  <name>Tarea 3: Documentar scope DB de cada módulo</name>
  <files>.planning/phases/2-functional-module-identification/SCOPE-MODULOS.md</files>
  <action>
    Para cada módulo candidato:
    Usa `mcp__project2context__query_classes` para obtener los modelos del módulo.
    Para cada modelo, usa `mcp__project2context__get_function_details` para leer el modelo y extraer:
    - Nombre de la tabla ($table o nombre inferido por convención)

    Agrega bajo cada módulo en SCOPE-MODULOS.md:

    | Tabla | Tipo | Relaciones con Otros Módulos |
    |-------|------|------------------------------|
    | [nombre] | Propia / Compartida / FK externa | [módulos relacionados] |

    Las tablas compartidas son puntos críticos de acoplamiento — márcalas con ⚠️.
  </action>
